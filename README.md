# Download Speed Test

Консольный скрипт для проверки скорости скачивания по URL.

Скрипт выполняет **10 последовательных GET-запросов** к указанному адресу, дожидается полного ответа на каждый запрос, считает среднее время запроса, общий объём скачанных данных и среднюю скорость скачивания.

---

## Требования

- Python 3.8 или выше
- Сторонние зависимости не требуются

## Запуск

### Запуск с указанием URL

```bash
python3 speed_test.py https://example.com/image.jpg
```

Пример с тяжелой картинкой:

```bash
python3 speed_test.py https://images.wallpaperscraft.ru/image/single/bmw_avtomobil_belyj_218881_3840x2160.jpg
```

---

### Запуск без URL

```bash
python3 speed_test.py
```

В этом случае скрипт попросит ввести адрес:

```text
Вставьте URL картинки или используйте по умолчанию:
```

Варианты поведения:

- ввести URL и нажать `Enter` — будет использован введенный адрес;
- просто нажать `Enter` — будет использован URL по умолчанию.

URL по умолчанию:

```text
https://images.wallpaperscraft.ru/image/single/bmw_avtomobil_belyj_218881_3840x2160.jpg
```

---

### Запуск с измененным таймаутом

По умолчанию таймаут ожидания данных одного запроса составляет 30 секунд.

Изменить таймаут можно так:

```bash
python3 speed_test.py https://example.com/image.jpg --timeout 60
```

---

### Запуск без меню после проверки

Если нужно выполнить ровно одну проверку и завершиться, используйте флаг `--once`:

```bash
python3 speed_test.py --once https://example.com/image.jpg
```

или:

```bash
python3 speed_test.py --once
```

## Единицы измерения

| Параметр | Единица | Обозначение | Пояснение |
|---|---:|---|---|
| Время запроса | секунды | `s` | Время одного полного GET-запроса |
| Общий объем данных | мегабайты | `MB` | Скачанные данные |
| Скорость скачивания | мегабайты в секунду | `MB/s` | Основная единица скорости |
| Скорость скачивания | мегабиты в секунду | `Mbit/s` | Дополнительная единица для сетевого контекста |

Используется десятичная система:

```text
1 MB = 1 000 000 bytes
```

Перевод скорости:

```text
Mbit/s = MB/s * 8
```

Пример:

```text
4.600 MB/s = 36.800 Mbit/s
```

## Как считается скорость

Скрипт выполняет 10 запросов последовательно.

Для каждого запроса измеряется:

- время от начала запроса до получения полного ответа;
- количество скачанных байт.

Итоговая скорость считается по формуле:

```text
speed = total_bytes / total_time
```

где:

- `total_bytes` — суммарный объем всех скачанных данных;
- `total_time` — суммарное время всех 10 запросов.

Также выводится среднее время одного запроса:

```text
average_time = total_time / 10
```

## Логика работы скрипта

1. Принимает URL:
   - из аргумента командной строки;
   - либо запрашивает у пользователя;
   - либо использует URL по умолчанию.

2. Проверяет корректность URL.

3. Проверяет, разрешается ли хост через DNS.

4. Выполняет 10 последовательных GET-запросов.

5. Каждый запрос читается до полного получения ответа.

6. После каждого запроса печатается:
   - номер запроса;
   - время запроса;
   - объем скачанных данных.

7. После всех запросов печатается итоговая статистика:
   - количество запросов;
   - среднее время запроса;
   - общий объем скачанных данных;
   - средняя скорость скачивания.

8. После проверки открывается меню дальнейших действий.

## Внутренние ограничения

### Максимальное время одного запроса

В скрипте задан внутренний лимит:

```python
MAX_REQUEST_TIME_SECONDS = 600.0
```

Единица измерения — секунды.

Если один запрос длится дольше этого лимита, проверка прерывается с ошибкой.

Значение `600.0` означает 10 минут на один запрос.

---

### Таймаут ожидания данных

Параметр `--timeout` отвечает за таймаут сокета, то есть за ожидание активности от сервера.

По умолчанию:

```text
30 секунд
```

Важно различать:

- `--timeout` — таймаут ожидания данных внутри запроса;
- `MAX_REQUEST_TIME_SECONDS` — максимальное общее время одного запроса.

## Меню после проверки

После завершения проверки скрипт предлагает действия:

```text
Дальнейшие действия:
  1 — повторить проверку с этим же URL
  2 — ввести другой URL
  0 — выйти
Выберите действие (1/2/0):
```

Правила:

- `1` — повторить проверку с текущим URL;
- `2` — ввести другой URL;
- `0` — выйти из программы.

Выход выполняется **только** при вводе `0`.

Если ввести другой символ или оставить поле пустым, скрипт напишет:

```text
Выбран неправильный пункт меню. Введите 1, 2 или 0.
```

и покажет меню снова.
